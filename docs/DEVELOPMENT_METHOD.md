# Development method and AI assistance

This project is part of **Miguel's Game Dev Lab**.

The development process is human-directed and AI-assisted.

Miguel Raposo defines the project goals, target hardware, technical and
publication constraints, acceptance criteria, testing decisions and final
approval. Physical-device testing and interpretation remain under human
control.

ChatGPT is used extensively for calculations, code drafting and modification,
debugging support, shell/build automation, technical analysis, documentation,
reproducibility work and repetitive repository operations.

AI-generated output is not accepted automatically. It is reviewed against the
intended design, available evidence and real-hardware behaviour and may be
modified or rejected.

The workflow uses explicit checkpoints, hashes, durable local project state,
feedback bundles and validation gates so decisions and failures remain
recoverable between development sessions.

The public lab-wide description of this method is maintained at:

https://raposomiguel50.github.io/method/
