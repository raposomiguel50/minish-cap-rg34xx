## Reproducibility qualification

The exact isolated P13.1 build worktree was not retained.

Accordingly this project does not claim byte-for-byte reproducibility of the
private V1 from this publication candidate.

The retained evidence establishes the validated V1 identity, upstream pin and
runtime/integration history.
